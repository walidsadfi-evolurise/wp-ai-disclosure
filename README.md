# AI Disclosure for WordPress

[![CI](https://github.com/walidsadfi-evolurise/wp-ai-disclosure/actions/workflows/ci.yml/badge.svg)](https://github.com/walidsadfi-evolurise/wp-ai-disclosure/actions/workflows/ci.yml)
[![License: GPL-2.0-or-later](https://img.shields.io/badge/License-GPL--2.0--or--later-blue.svg)](LICENSE)

**Tell visitors when they are talking to an AI.** Article 50 of the EU AI Act, applicable since 2 August 2026, requires that people interacting with an AI system are informed of it, unless it is obvious from the context. Most chat widgets and AI-assisted forms on WordPress sites say nothing. This plugin fixes that in two minutes and keeps a count of impressions for your records.


## What it does

- **Auto-detects 17 chat and assistant widgets** (Intercom, Crisp, Tidio, Drift, HubSpot, Zendesk, tawk.to, Freshchat, LiveChat, Brevo, Chatbase, Voiceflow, Botpress, Dialogflow, WPBot, AI Engine, Kognetiks) from their loader scripts, server-side and in the DOM, and shows the notice only on pages where one is present.
- **Your own selectors**: add `#my-assistant` or `form.ai-generated` and the notice appears wherever they match.
- **Three placements**: bottom banner, top banner, or inline right before the widget.
- **Block and shortcode** (`[ai_disclosure]`) for AI-generated content sections and custom chat UIs.
- **Default wording in 6 languages** (EN, FR, DE, ES, IT, NL) following the site locale, fully editable.
- **Audit trail**: a daily impression counter (no personal data, no cookies) with CSV export, so you can show that the notice was displayed.
- **Accessible**: `role="note"`, `aria-live="polite"`, keyboard-dismissible, respects reduced motion and dark mode.
- **Cache-friendly**: the counter uses `sendBeacon` without a nonce, so full-page caches keep working.

## Install

Until the plugin is on wordpress.org: download the latest release zip from the [Releases](https://github.com/walidsadfi-evolurise/wp-ai-disclosure/releases) page and upload it in *Plugins → Add New → Upload*. Then go to *Settings → AI Disclosure*.

Requires WordPress 6.4+ and PHP 8.1+.

## Settings

| Setting | Meaning |
| --- | --- |
| When to show | *Automatically* (detected widget or selector), *On every page*, or *Only where the block/shortcode is placed* |
| Notice text | Empty = locale default. Keep it short; it must be read before the first message |
| Position | Bottom banner, top banner, inline |
| Dismissible | Lets visitors close the banner for the browser session |
| Learn more link | Optional link to your AI policy page |
| Detected widgets | Untick vendors you do not want to trigger the notice |
| Extra CSS selectors | One per line |
| Audit trail | Daily counts + CSV export |

## Shortcode and block

```
[ai_disclosure]
[ai_disclosure text="This summary was generated by AI and reviewed by our team." position="inline"]
```

The **AI Disclosure** block (Widgets category) renders the same notice with an editable text.

## Development

```bash
composer install
composer check      # phpcs (WordPress Coding Standards) + phpunit (Brain Monkey, no WordPress needed)
```

The logic that matters (widget detection, notice rendering and escaping, settings sanitisation, the counter) is pure PHP and unit-tested without a WordPress install.

## Not legal advice

This plugin helps you display a transparency notice. Whether your use case falls under article 50, and the exact wording you need, is a question for your counsel. The default text is deliberately conservative.
