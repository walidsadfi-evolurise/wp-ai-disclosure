# Changelog

## [0.1.0] - 2026-11-04

### Added

- Automatic detection of 17 chat/assistant widgets (server-side script scan + DOM observer).
- Bottom/top banner and inline placement, dismissible per session, accessible markup.
- Block and `[ai_disclosure]` shortcode.
- Default notice text in EN, FR, DE, ES, IT, NL following the site locale.
- Daily impression counter with CSV export; no personal data.
- Settings page under Settings → AI Disclosure; uninstall cleanup.
- PHPCS (WordPress Coding Standards) and PHPUnit/Brain Monkey test suite, CI on PHP 8.0–8.4.
